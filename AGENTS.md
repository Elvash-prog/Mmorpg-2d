# Entregas

O usuário prefere receber as entregas deste projeto pelo GitHub, com um link ativo para **Download ZIP**, em vez de links para caminhos internos do ambiente. Após implementar e validar uma entrega solicitada, publique os commits no repositório configurado e forneça o link do arquivo ZIP correspondente ao commit publicado. Preserve alterações existentes e nunca use push forçado. Se a publicação estiver bloqueada, informe o bloqueio; não apresente um link não verificado como download disponível.

O ZIP contém o projeto-fonte Godot. Só anuncie um executável de PC ou APK Android quando esse artefato tiver sido realmente gerado e validado.
